# Dota 2 Guide

Guia de lane, mid e late game baseado em estratégias de jogadores profissionais.

## Early Game (Lane Phase)
- Focus on last hit
- Avoid unnecessary fights
- Control creep equilibrium

## Mid Game
- Rotate with your team
- Take towers
- Secure objectives (Roshan)

## Late Game
- Stay with team
- Buy important items (BKB, etc)
- Positioning is everything
